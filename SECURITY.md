# Security Policy

Forge is pre-release software and is not production-certified yet; see the
[threat model](docs/threat-model.md) for the controls it targets.

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub's
[private vulnerability reporting](https://github.com/rocketinsidecorp/forge-rust/security/advisories/new)
("Report a vulnerability" on the repository's Security tab). Do not open public
issues or pull requests for security problems.

Include the affected crate/version or commit, a description of the impact, and
reproduction steps or a proof of concept if you have one. We aim to acknowledge
reports within 5 business days and will coordinate a fix and disclosure
timeline with you. Reporters are credited in the advisory unless they prefer
otherwise.

## Supported versions

Until the first release, only the latest `main` receives security fixes.
